
# DigiShop Backend Practice

A beginner backend development practice project focused on SQL Server and database operations.

## Project Description

This project is part of my learning process in backend development. It focuses on working with relational databases, writing SQL queries, and practicing basic database operations using Microsoft SQL Server.

## Database Information

**Database Name:** `DigiShopDB`

**Tables:**
- `Categories` – Stores product categories.
- `Products` – Stores product information.

## SQL Concepts Practiced

- Retrieving data using `SELECT`
- Adding records using `INSERT`
- Updating records using `UPDATE`
- Deleting records using `DELETE`
- Combining tables using `INNER JOIN`

## Project Files

| File | Description |
|---|---|
| `01_Create_And_View_Tables.sql` | Viewing table data |
| `02_Inner_Join.sql` | Retrieving related data from two tables |
| `03_Insert_Data.sql` | Practicing data insertion |
| `04_Update_Data.sql` | Practicing data updates |
| `05_Delete_Data.sql` | Practicing data deletion |

## Technologies & Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Project Goal

The goal of this project is to build a practical foundation in database management and SQL operations before moving on to backend development with Java and Spring Boot.
